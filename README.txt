YUBA CAFE WEBSITE
=================

Pages:
- index.html
- menu.html
- about.html
- gallery.html
- reservation.html
- contact.html

Assets:
- css/style.css
- js/script.js

How to run:
1. Extract the ZIP.
2. Open index.html in a browser.
3. Internet is required for Bootstrap CDN and the remote Unsplash images.
4. For development, you can use VS Code + Live Server.

Notes:
- Reservation and contact forms are frontend demo forms. They show a success toast but do not save data to a server.
- Replace image URLs with your own local images for production.
